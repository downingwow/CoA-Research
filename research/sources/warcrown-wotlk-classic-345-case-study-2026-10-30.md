# WarCrown — Wrath Classic 3.4.5 modern-client case study

- Website: https://warcrown.org/
- Research date: 2026-10-30
- Project type: live Wrath Classic private server; case study, **not confirmed open-source tooling**.

## Verified public claims
- WarCrown publicly advertises operation on a Wrath Classic **3.4.5** client and states it migrated its Crystalsong realm from 3.4.4 to 3.4.5 in September 2026.
- Official news: https://warcrown.org/news/warcrown-345-is-now-live
- Installation guide: https://warcrown.org/how-to-start-playing — its launcher is described as downloading, patching, verifying and configuring the client.
- Third-party report: https://www.privateserverhub.com/news/warcrown-moves-crystalsong-to-the-wrath-classic-3-4-5-client

## Relevance to CoA 3.4.3.54261 port
- Demonstrates a deployed modern Wrath Classic private-server approach; investigate authentication, launcher, hotfix/client data, and interface compatibility.
- **Do not infer** that WarCrown source code, client files, gateway, launcher code or class patches are public.
- Does not prove custom CoA class IDs, spells, talents, or custom assets work in 3.4.x.
- Maintain 3.4.3.54261 as primary baseline while treating 3.4.5 as an alternate case study.
