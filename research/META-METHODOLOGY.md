# Historical CoA meta and BiS reconstruction methodology
Maintainer: Uncle Bone. Updated 2026-10-29.

## Metrics
DPS and HPS per boss/phase/difficulty, median and 95th percentile when available, number of parses, encounter duration and date; Mythic+ key and run context separately. Track spec and class separately. A highest parse is not a representative ranking. Never mix all-damage with boss-only DPS or healing with damage.

## Tier lists
Each published tier requires exact formula, source snapshots, phase, difficulty, metric, date window and sample size. Label custom percentile thresholds as community-derived, not official Ascension tier ratings. Prefer minimum sample threshold and confidence bands where possible.

## BiS
Distinguish (a) original BisBeard published saved set, (b) reconstructed stat-weight candidates, (c) observed high-performing player gear, (d) simulated/verified optimal sets. Model armor/weapon eligibility, uniqueness, sockets, enchants, caps, procs, sets, talents, glyphs, tinkers and encounter-specific effects. Linear weights alone cannot prove BiS.

## Provenance
Keep original source URL, Git commit/hash, observed file checksum, capture timestamp if present, realm, class/spec identifiers, phase labels, and evidence status. No invented stats or items. Never expose private logs or identifiers; honor source licensing and API terms.
