# Historical CoA BisBeard preservation

The old Conquest of Azeroth BisBeard endpoint was **https://coa.bisbeard.com/**. Availability is unreliable or discontinued; avoid asserting a complete backup exists.

## Recovered references
- [CoA tier list historical data](https://github.com/Ryansousa10/coa-tier-list/tree/main/tools/data/raw):
  - `bisbeard-meta.json` — observed file approximately 33,873 bytes; contains metadata from historical BisBeard capture.
  - `bisbeard-items-p1.json` — observed approximately 18,457,734 bytes.
  - `bisbeard-items-p2.json` — observed approximately 8,069,215 bytes.
  - Additional rankings, boss stats, Mythic+ and other captures available in that folder.
- [BisBeard source scraper](https://github.com/Ryansousa10/coa-tier-list/blob/main/tools/scrape/bisbeard.mjs) — request/extraction code to document provenance.
- [BisBeard glyph archive](https://github.com/kevinvongmany/bisbeard-db) — `glyphs_ascension.ts`, observed around 509 KB.
- [BisBuddy](https://github.com/Leemo94/BisBuddy) — related reference.
- [BisBeard root](https://bisbeard.com/) — independent availability from discontinued CoA subdomain.

Preserved item rankings, stat weights, and glyph data help gear/talent guides. They **do not** establish live spell IDs, simulation accuracy, or current phase BiS without version comparisons. The user prefers useful historical data even without a guarantee of present-day currency, so retain date/provenance rather than discarding it.
